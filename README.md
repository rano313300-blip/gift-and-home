# فروشگاه دورهمی (جنگو)

طراحی و توسعه: **AMIR AMMARZAD**

فروشگاه اینترنتی لوازم آشپزخانه و هدیه با سبد خرید، ثبت سفارش، پرداخت آنلاین، سه روش ارسال (پست، پیشتاز، تیپاکس) و پنل مدیریت.

## راه‌اندازی سریع (برای تست روی کامپیوتر خودتان)

پایتون ۳.۱۰ یا بالاتر لازم است.

**ویندوز:** فایل `setup.bat` را اجرا کنید.
**لینوکس/مک:** `./setup.sh`

این اسکریپت محیط مجازی می‌سازد، وابستگی‌ها را نصب می‌کند، دیتابیس را می‌سازد، ۱۲ محصول نمونه اضافه می‌کند، از شما نام‌کاربری مدیر می‌گیرد و سایت را روی http://127.0.0.1:8000 اجرا می‌کند.

دستی:
```
python -m venv .venv && source .venv/bin/activate     # ویندوز: .venv\Scripts\activate
pip install -r requirements.txt
python manage.py makemigrations shop
python manage.py migrate
python manage.py seed_products
python manage.py createsuperuser
python manage.py runserver
```
پنل مدیریت: http://127.0.0.1:8000/admin/

اجرای تست‌ها: `python manage.py test`

## صفحه‌ها

خانه، فروشگاه (جستجو، دسته‌بندی، مرتب‌سازی، صفحه‌بندی)، صفحه محصول، سبد خرید (با بسته‌بندی کادویی و کارت پیام)، ثبت سفارش و پرداخت، صفحه سفارش، پیگیری سفارش (کد سفارش + موبایل)، درباره ما و تماس (پیام‌ها در پنل مدیریت ذخیره می‌شوند).

## پنل مدیریت

- **محصولات:** افزودن، تصویر، قیمت، قیمت قبل از تخفیف، موجودی (قابل ویرایش مستقیم در لیست)
- **سفارش‌ها:** جزئیات گیرنده، اقلام، شماره پیگیری بانکی. کد رهگیری پست/تیپاکس را در سفارش وارد کنید و با گزینه‌های بالای لیست وضعیت را به «در حال آماده‌سازی / ارسال شده / تحویل داده شده» تغییر دهید. کاربر با صفحه «پیگیری سفارش» همان را می‌بیند.
- **پیام‌های تماس**

## پرداخت

دو حالت دارد (متغیر `PAYMENT_GATEWAY`):

1. `mock` (پیش‌فرض): درگاه آزمایشی داخلی، برای توسعه. پول جابه‌جا نمی‌شود.
2. `zarinpal`: درگاه واقعی زرین‌پال.

**اتصال به زرین‌پال واقعی:**
1. در zarinpal.com ثبت‌نام و احراز هویت کنید، وب‌سایت خود را ثبت و درگاه پرداخت (مرچنت) بگیرید. برای فعال‌شدن درگاه معمولاً دامنه و نماد اعتماد الکترونیکی (اینماد) لازم است.
2. ابتدا با `ZARINPAL_SANDBOX=1` و یک مرچنت‌آیدی ۳۶ کاراکتری تست کنید:
   ```
   PAYMENT_GATEWAY=zarinpal
   ZARINPAL_MERCHANT_ID=xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
   ZARINPAL_SANDBOX=1
   ```
3. برای پرداخت واقعی `ZARINPAL_SANDBOX=0` و مرچنت واقعی را بگذارید.

جریان پرداخت: ثبت سفارش (قیمت‌ها از دیتابیس محاسبه می‌شود) → درخواست به درگاه → انتقال به بانک → بازگشت به `/payment/callback/` → **تأیید (verify) از سمت سرور** → کسر موجودی و ثبت پرداخت (بدون تکرار در صورت رفرش). مبلغ به ریال ارسال می‌شود.
برای درگاه بانکی دیگر، کلاس جدیدی با دو متد `request` و `verify` در `shop/payments.py` اضافه کنید.

## هزینه ارسال

در `shop/shipping.py` قابل تنظیم است: هزینه پایه هر روش، مبلغ هر کیلوگرم اضافه، حد ارسال رایگان (پست عادی بالای ۳ میلیون تومان) و هزینه بسته‌بندی کادویی. نرخ‌ها را با تعرفه روز پست و تیپاکس تطبیق دهید. محاسبه براساس وزن محصولات است (فیلد وزن در محصول).

## انتشار روی سرور

1. `pip install -r requirements-prod.txt`
2. متغیرهای `.env.example` را روی سرور تنظیم کنید (حتماً `DJANGO_DEBUG=0` و یک `DJANGO_SECRET_KEY` تصادفی)
3. `python manage.py migrate && python manage.py collectstatic --noinput`
4. اجرا با `gunicorn config.wsgi` پشت nginx (با HTTPS). پوشه `media/` را مستقیم با nginx سرو کنید.
5. برای دیتابیس واقعی، متغیرهای `POSTGRES_*` را تنظیم کنید.

## چیزهایی که هنوز نیست

پیامک تأیید سفارش، حساب کاربری مشتری، کد تخفیف، و اتصال خودکار به API پست/تیپاکس برای صدور بارنامه. ساختار پروژه برای افزودن همه این‌ها آماده است.

## عکس واقعی محصولات و صفحه اول

- **عکس محصولات:** در پنل مدیریت برای هر محصول عکس آپلود کنید، یا عکس‌ها را در پوشه `media_import/` بگذارید (نام فایل = شماره محصول، مثلاً `3.jpg`) و `python manage.py import_images` را اجرا کنید.
- **عکس صفحه اول:** فایل `static/img/hero.jpg` (پیشنهاد: افقی یا مربع، حداقل ۱۰۰۰ پیکسل) را بگذارید؛ خودکار جای تصویر گرافیکی را می‌گیرد.
- **آیکون سایت (favicon):** در `static/img/` است.
